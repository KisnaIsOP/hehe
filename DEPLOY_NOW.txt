🎯 DEPLOYMENT STEPS (Follow in order):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: GET DISCORD BOT TOKEN
══════════════════════════════════════════════════════════════════════════
  1. Go to: https://discord.com/developers/applications
  2. Click "New Application" (or select existing)
  3. Give it a name (e.g., "ChhotaBot")
  4. Go to "Bot" section in sidebar
  5. Click "Reset Token" → Copy and save the token
  6. ⚠️  SCROLL DOWN TO "Privileged Gateway Intents"
  7. ✅ ENABLE "MESSAGE CONTENT INTENT" ← THIS IS CRITICAL!
  8. Click "Save Changes"

  INVITE BOT TO YOUR SERVER:
  ─────────────────────────
  1. Go to "OAuth2" → "URL Generator"
  2. Select Scopes: ✅ bot
  3. Select Bot Permissions:
     ✅ Send Messages
     ✅ Read Message History
     ✅ Attach Files
  4. Copy generated URL
  5. Open URL in browser → Select server → Authorize


STEP 2: GET OPENROUTER API KEY
══════════════════════════════════════════════════════════════════════════
  1. Go to: https://openrouter.ai
  2. Sign up / Login
  3. Go to: https://openrouter.ai/keys
  4. Click "Create API Key"
  5. Copy the key (starts with "sk-or-")
  6. Save it securely


STEP 3: RUN AUTOMATED SETUP SCRIPT
══════════════════════════════════════════════════════════════════════════
  Open PowerShell in the coding/chhotabot folder and run:
  
  .\deploy_setup.ps1
  
  This script will:
  ✓ Check if Git is installed
  ✓ Initialize Git repository
  ✓ Create initial commit
  ✓ Guide you through GitHub connection


STEP 4: CREATE GITHUB REPOSITORY
══════════════════════════════════════════════════════════════════════════
  1. Go to: https://github.com/new
  2. Repository name: "chhotabot-discord" (or your choice)
  3. ⚠️  DO NOT check "Initialize with README"
  4. Click "Create repository"
  5. Copy the repository URL (ends with .git)


STEP 5: PUSH CODE TO GITHUB
══════════════════════════════════════════════════════════════════════════
  In PowerShell (in coding/chhotabot folder):
  
  git remote add origin https://github.com/YOUR_USERNAME/chhotabot-discord.git
  git branch -M main
  git push -u origin main
  
  Replace YOUR_USERNAME with your actual GitHub username!


STEP 6: DEPLOY TO RAILWAY
══════════════════════════════════════════════════════════════════════════
  1. Go to: https://railway.app
  2. Click "Login" → Login with GitHub
  3. Click "New Project"
  4. Select "Deploy from GitHub repo"
  5. Authorize Railway to access your repos (if asked)
  6. Select your "chhotabot-discord" repository
  7. Wait for Railway to detect Node.js project


STEP 7: ADD ENVIRONMENT VARIABLES IN RAILWAY
══════════════════════════════════════════════════════════════════════════
  In Railway Dashboard → Your Service → "Variables" tab:
  
  Click "+ New Variable" and add:
  
  ┌─────────────────────────┬──────────────────────────────────────────┐
  │ Variable Name           │ Value                                    │
  ├─────────────────────────┼──────────────────────────────────────────┤
  │ DISCORD_TOKEN           │ <paste your Discord bot token>           │
  │ OPENROUTER_API_KEY      │ <paste your OpenRouter API key>          │
  │ OPENROUTER_MODEL        │ google/gemma-3-4b-it:free   (optional)   │
  │ RATE_LIMIT_PER_MINUTE   │ 10                          (optional)   │
  │ CACHE_TTL_SECONDS       │ 300                         (optional)   │
  └─────────────────────────┴──────────────────────────────────────────┘
  
  ⚠️  Only DISCORD_TOKEN and OPENROUTER_API_KEY are required!
  
  After adding variables, Railway will automatically redeploy.


STEP 8: WATCH DEPLOYMENT
══════════════════════════════════════════════════════════════════════════
  In Railway Dashboard → "Deployments" tab:
  
  Click on latest deployment to see logs.
  
  ✅ SUCCESS looks like this:
  
  ✅ All sanity checks passed! Starting bot...
  ✅ ChhotaBot is online!
  📝 Logged in as ChhotaBot#1234
  🌐 Serving X guilds
  
  If you see these messages, YOUR BOT IS LIVE! 🎉


STEP 9: TEST IN DISCORD
══════════════════════════════════════════════════════════════════════════
  Go to your Discord server and type:
  
  !help
  !ai Hello! Can you hear me?
  !ai --mode=short What is AI?
  @ChhotaBot Hi there!
  
  Bot should respond to all these commands!

❌ TROUBLESHOOTING COMMON ISSUES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Bot shows as online but doesn't respond
Solution: 
  → Check MESSAGE CONTENT INTENT is enabled in Discord Developer Portal
  → This is the #1 reason bots don't work!
  → Go back to Step 1, point 6-7

Problem: "Invalid token" error in Railway logs
Solution:
  → Check DISCORD_TOKEN variable is correct
  → Make sure you copied the full token (no spaces)
  → Try generating new token in Discord Developer Portal

Problem: "401 Unauthorized" for OpenRouter
Solution:
  → Check OPENROUTER_API_KEY variable is correct
  → Verify key starts with "sk-or-" or "sk-"
  → Generate new key at https://openrouter.ai/keys

Problem: Bot not in my Discord server
Solution:
  → Go back to Step 1 and follow "INVITE BOT TO YOUR SERVER"
  → Make sure you selected correct server when authorizing

Problem: Deployment keeps failing
Solution:
  → Check Railway deployment logs for specific error
  → Verify all environment variables are set correctly
  → Try clicking "Redeploy" in Railway dashboard
